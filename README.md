# BuildNorm AI

**Интеллектуальная нормативно-техническая платформа для строительства.**

BuildNorm AI — российский SaaS-проект для поиска, анализа и практического применения нормативной документации в строительстве.

## Цель MVP

Пользователь задаёт инженерный вопрос и получает ответ, основанный на доступных нормативных источниках, с проверяемыми ссылками на документы, редакции и конкретные пункты.

## Принципы проекта

1. **Evidence first:** нормативное утверждение должно иметь проверяемое основание.
2. **Версионность:** редакции и изменения документов хранятся отдельно; история не перезаписывается.
3. **Никаких выдуманных норм:** система не генерирует неподтверждённые номера пунктов, значения и статусы.
4. **Правомерное использование:** документы подключаются только при наличии подходящего правового основания и разрешений.
5. **Модульность:** LLM, поиск, обработка документов и интерфейс не зависят от одного поставщика.

## Текущий статус

Репозиторий находится на этапе начального фундамента. Реализуется минимальный backend и локальная инфраструктура для последующей разработки RAG-поиска.

## Стек MVP

- Backend: Python, FastAPI, Pydantic Settings
- Database: PostgreSQL
- Vector search: Qdrant
- Frontend: отдельное приложение React + TypeScript (следующий этап)
- AI: сменяемый LLM provider; конкретная модель выбирается после тестирования
- Local development: Docker Compose

## Быстрый старт

Требования: Docker Desktop с Compose plugin и Python 3.11+.

1. Скопировать `.env.example` в `.env`.
2. Запустить инфраструктуру:

   ```bash
   docker compose up -d
   ```

3. Установить backend-зависимости:

   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   # macOS/Linux:
   # source .venv/bin/activate
   pip install -e ".[dev]"
   ```

4. Запустить API:

   ```bash
   uvicorn app.main:app --app-dir backend --reload
   ```

5. Проверить:
   - Health: http://localhost:8000/api/v1/health
   - OpenAPI: http://localhost:8000/docs

## Важное ограничение

BuildNorm AI — инженерный информационный инструмент, а не орган экспертизы и не замена проектировщику, специалисту строительного контроля или юридической проверке. До коммерческого использования необходимо обеспечить правомерность доступа и обработки нормативных текстов, а также проверить применимость каждого источника.
